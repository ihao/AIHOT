# 9BTC 每日模型费用降至 10 元以内的方案

核对时间：2026-10-04 13:13，北京时间。此次只读生产配置和费用汇总，未发起付费模型请求，未修改生产配置。

## 结论

建议按全站模型费用设计 10 元以内目标：先增加金额预算，再用代表性新闻样本评测百炼 DeepSeek-V4.1-Flash 的普通证据核验能力。通过后让它承担普通核验，保留 Qwen3.8 Max 处理复杂、高风险和冲突材料。不要取消独立核验、下调精选门槛或自动放行缺证内容。

金额预算可确定性地限制本站发出的费用；模型替换能否维持产出与准确度，需要评测。预算用完后推迟待处理内容，是守住成本上限的实际取舍。

## 建议实施顺序

### 1. 增加费用预算，先让上限生效

建议日常目标 8 元，本站模型费用按保守价格计到 9 元停止新请求，给 10 元目标留下余量。自然日按北京时间计，同时保留滚动 24 小时限制，避免午夜集中发送。

在发送前，将输入的保守 token 上界和最大输出费用原子预占到全站预算；发送后按 usage 结算。未收到 usage 的 pending/unknown 请求保留预占，不按零费用处理。缓存命中可以降低已发生费用估算，发送前不依赖未来命中。重试、改写、向量和模型评测都使用同一费用账本，不通过更换服务绕开限额。

增加金额约束需要代码和增量数据库变更；只填写当前价格表不能产生金额熔断。费用上限只覆盖经过本站回执链路的调用，不能约束同账号其他应用。

### 2. 普通核验评测廉价模型，Max 保留有限预算

优先评测当前百炼账号此前已完成基础兼容性试用的 `deepseek-v4.1-flash`。之前试用只有合成边界样本，不能视为真实新闻质量验收。

用约 100 条代表性材料给出人工标准答案，比较错误放行、错误拒绝、数字与主体混淆、测试网/主网、提案/实施、引用可定位性、结构合规、实际 token 和重试成本。费用计入当天模型预算；不自动启动付费实验。

合格后先让普通官方信息使用 DeepSeek 独立核验，复杂监管、攻击、治理阶段和材料矛盾使用 Max。模型不确定不能直接接受；预算不足也不能接受。建议先以 Max 约 10% 的 token 工作量做成本规划，高风险工作量超过额度时延后，不为了满足比例降低核验标准。

同当前 24 小时输入/输出 token 换价，若 90% 核验工作量使用 DeepSeek、10% 保留 Max，DeepSeek 不计缓存优惠、Max 保留当前缓存比例，连同现有 Flash 的目录估算约 3.44–4.69 元，不含向量、重复升级复核或实验。路由必须保证非高风险样本和 token 分布满足该假设；这不是已验证账单，更不是同质量保证。

### 3. 控制证据与输出长度

对超长原文选择与待核验主张对应的连续原文段落，保存来源、位置、上下文及否定/条件/事实阶段。不能只传模型生成摘要，也不能按字符硬切掉关键证据；材料不足时停止公开。

核验输出只保留必要判断、关键主张、短引用和拒绝原因，并在代表性样本上确认覆盖率。当前约一半 Max 估算费用来自输出，输入压缩之外也要减少重复主张与冗长引用。

已有缺证止损、成功回执复用和未知结果等待继续保留；不要把本次已经部署的节省再算成未来新增节省，不因换策略触发历史全量重审。

### 4. 缓存和批处理作为补充

固定规则放在提示词前部，变化材料放后部，以实际 `cached_tokens` 验证命中。当前 Max 输入缓存率约 34.5%，所以缓存并非尚未利用的全部新收益。

北京 `qwen3.8-max` 的 Batch File 输入/输出单价为实时的 50%，但会改变实时处理方式，且不能叠加上下文缓存优惠。按 25 元简单减半仍为 12.5 元，不能独立完成目标；也不能假定 Batch Chat 一样半价。
