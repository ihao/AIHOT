日期：2026-10-10。目标：将已合并的上游 4.0 更新部署到 `https://9btc.com`，日报恢复上游原始的北京时间每天 08:00；周报每周一 10:00，月报每月 1 日 10:30。

## 发布范围

- 保留站点 Web3 配置、来源运行设置、模型与费用保护。
- 历史文章复用已保存结果，不重新购买分析；已有报告不重写，不批量补旧缺期。
- 排程仍每半小时检查，只生成每类报告最新到期一期。
- 上传文件由 API 的数据卷持有，本机备份相应从 API 导出；网页容器不持有数据库与后台凭据。

## 发布前验证
