# 9BTC 首批模型接入与验收

2026-09-30。状态：接入方案已整理，模型供应商和凭据尚未确定，EU 模型调用仍关闭。本文件与[信源试运行建议](research/2026-09-30-web3-sources-launch-pilot.md)配套，首版先完成真实内容的人工审核闭环。

## 站长需要提供的资源

只需先确定是否已有可用的 OpenAI 兼容 API，以及供应商名称。聊天中不要发送 API key。已有服务先复用；没有现成服务时，建议用 DeepSeek 官方接口做小规模试运行，不同时开通多个模型或付费采集服务。

确定服务后，在本机仓库根目录的 `.env.model.local` 填入专用 API key，文件权限设为 `0600`。该路径被当前 `.gitignore` 的 `.env.*` 规则排除；配置前再用 `git check-ignore` 核实。密钥由受控 SSH 通道写入 EU `/srv/9btc/.env`，不输出到聊天、日志或 Git。若站长已有独立的本机密钥文件，只需提供文件路径，由部署操作读取，无需重复录入。

以下是 **DeepSeek 候选配置**，尚未应用。2026-09-30 已核对[官方模型文档](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，`deepseek-flash` 支持 JSON Output，默认思考模式开启，本项目试运行显式关闭。其他供应商需重新核对模型名和专有参数。

```dotenv
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=
LLM_MODEL=deepseek-flash
LLM_EXTRA_JSON={"thinking":{"type":"disabled"}}
LLM_JSON_MODE=true
LLM_VISION=false
COLLECT_ENABLED=false
MODEL_CALLS_ENABLED=false
```

各步骤先统一使用 `LLM_*`；部署时核对 `PREFILTER_MODEL`、`SCORE_MODEL`、`UNDERSTAND_MODEL`、`SUMMARIZE_MODEL`、`STRUCTURE_MODEL`、`GROUP_MODEL`、`GROUP_REVIEW_MODEL`、`DIGEST_MODEL`、`REPORT_MODEL`、`TRANSLATE_MODEL`、`MONITOR_MODEL` 是否残留不同供应商的覆盖值。向量、图片理解、Jina、社交平台采集和外部推送暂不启用。

## 调用控制

项目默认 `llm` 熔断值为 300 次/分钟、6,000 次/小时、40,000 次/滚动 24 小时，偏宽，不直接作为 9BTC 首次试运行值。建议由部署操作通过现有后台设置逻辑设置 `llm` 为 **10 / 60 / 200**，保留修改原因和审计记录。当前只是建议，尚未设置。

熔断统计的是实际发出的请求尝试，重试也计数；同一条资讯可能经历多次模型请求，200 次不等于处理 200 条资讯。达到上限后暂停相应调用，待时间窗释放或人工调整，不绕开回执和预算机制。

这是调用次数控制，**不是人民币硬上限**。现有 LLM 回执记录 token usage，但没有自动填入人民币成本。先用少量真实样本记录输入、输出、失败与重试；按当时供应商单价估算，再与供应商账单核对。若供应商支持账户消费限制，可同时设置；不以调用次数推断确定费用。

## 执行顺序

1. 确认模型服务并安全配置专用凭据；检查文件权限、Git 排除和步骤覆盖值，仅输出是否已配置，不输出值。
2. 核对 `llm` 预算行并应用试运行限制。后台 worker 保持采集和模型调用关闭。
3. 经站长授权的小额试调用，通过项目 `chatJson` / `paidRequest` 入口验证认证、JSON 结构、中文输出和 usage 回执。只给验收进程打开模型阀，不让后台 worker 同时批量运行；失败先定位，不无限重试。
4. 导入站长已选定的信源，首次每源最多 3 条，全部保持待审。先单次限量采集和分析，再考虑启动定期任务。
5. 对约 12–18 条原文做真实流水线验证：初筛、正文、分类、中文摘要、事件归组、待审列表。记录淘汰理由；非 Web3 的 SEC 文章、纯营销和价格喊单应被筛除。陈旧内容保留原始日期。
6. 检查摘要中的数字、主体、时间、链、事件阶段和研究归属；发现错误修正并重跑受影响步骤。重大安全与监管事件保持人工批准。
7. 站长在夜间审核中批准真实内容；生成并审核日报草稿，验证草稿和未批准资讯没有出现在首页、RSS、API、MCP 等公开出口。
8. 验收通过后开放 EU Caddy 的 `9btc.com` 入口，验证 HTTPS、真实内容、后台、公开出口和备份。再启用已选信源的定期采集；首批自动公开白名单保持关闭。

第 7 步涉及真实内容的站长审核，不使用测试批准或合成新闻替代。若部分信源回填内容全被筛除，验收数量以真实相关样本为准，不为凑数公开无关文章。

## 完成标准

- 可从原文追溯真实中文摘要、审核决定与已发布日报；站长能在约 30 分钟内完成首批优先审核，积压继续私有待审。
- 模型调用有回执与用量，熔断实际生效，网页访问不触发模型。
- `https://9btc.com` 展示已审核 Web3 内容，待审/驳回内容和日报草稿不公开。
- EU 本地备份与 naban 拉取副本可校验并恢复。首次定时运行需另行观察，手工演练成功不等于已验证定时调度。

以上是待执行验收条件，不能据此宣称已经完成模型接入或正式上线。隐私页面等非主功能按站长决定留到上线后优化。
