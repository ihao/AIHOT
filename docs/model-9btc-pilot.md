2026-10-01。供应商已确定为阿里云百炼，站长提供的 CSV 已安全读取；原文件未改动。凭据保存在本机 Git 忽略的 `.env.model.local`，权限 0600。EU 采集、后台模型调用及公共入口仍关闭，自动发布代码尚在实施。

## 已确认的模型资源

通过 CSV 提供的工作空间端点查询模型目录，返回总数 518；已检查第一页 100 项并确认以下两个调用 ID、结构化输出能力与目录价格。目录存在并不单独证明调用权限，因此另在隔离 PG17 测试库通过项目 `chatJson` / `paidRequest` 做了两次真实调用。

| 步骤 | 模型 | 输入 / 输出目录价，元每百万 tokens |
| --- | --- | --- |
| 预筛、价值评分、中文摘要、结构抽取及归组 | `qwen3.8-flash` | 0.8 / 2.7 |
| 独立摘要证据核验 | `qwen3.8-max` | 12 / 36 |

模型分工是首版实施选择，尚不代表经过真实 Web3 样本效果评测。核验使用更强的模型，也不能把同供应商另一次请求当作独立事实来源。全部请求关闭思考模式并采用 JSON 输出；正文材料与确定性引文检查仍是公开门禁。

[模型目录 API](https://help.aliyun.com/zh/model-studio/list-models)返回的 `model` 才是调用 ID。必须保留站长提供的工作空间/地域端点，不擅自替换为通用地址。`enable_thinking=false` 是请求顶层字段，参见[官方说明](https://help.aliyun.com/zh/model-studio/deep-thinking)。API key 不写入本文件、聊天或 Git。

本机配置同时准备 `LLM_*` 与共享的 `DASHSCOPE_*`。各常规 capability 显式指向 `qwen3.8-flash`，`VERIFICATION_MODEL=qwen3.8-max`；两种命名预设共享 `dashscope` 回执服务，正式试运行可用一个共同预算控制，不把两行各 200 次误当合计 200 次。

## 接入验证证据

[去除凭据的接入结果](research/2026-10-01-bailian-connectivity.json)记录模型、usage、测试回执与估算费用。Flash 中文 JSON 和 Max 的四条主张核验均成功；两次共用 1,036 输入、400 输出 tokens，无缓存命中，目录价估算合计 **0.0232917 元**。实际账单、活动价格和账户权限以百炼为准。

这两次使用明确标记的内部合成材料，仅写隔离测试库；没有向业务库写入新闻，没有采集或公开任何文章。连接成功不等于自动发布上线，也不能据此断言核验准确率。

## 调用与部署控制

首次真实内容试运行，将实际使用的共同模型服务 `dashscope` 限制为 **10 次/分钟、60 次/小时、200 次/滚动 24 小时**，通过现有预算设置入口写入原因和审计。未使用的供应商不配置凭据。验证命名预设确实走同一服务，避免 `default` 的 `llm` 回执绕过共同额度。

预算统计实际发出的尝试，重试也计数；200 次不等于处理 200 篇资讯，也不是人民币硬上限。回执保留 token usage；费用按实际模型、缓存 token 和当时目录价估算，再与账单核对。模型错误与超时按已有有限恢复策略处理，不无限重试。

部署时安全传送忽略文件中的模型配置，合并到 EU 环境文件，保留既有数据库和认证配置。密钥不出现在 SSH 命令参数或日志，文件权限 0600。先安装验收通过的固定代码版本，后台阀仍关闭；仅给限定样本的验收进程打开模型与采集阀。
