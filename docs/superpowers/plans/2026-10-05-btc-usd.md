# BTC USD Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development to implement this plan. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add Coinbase BTC/USD current quotes and immutable news ingestion quotes with 5 minute collection and 10 minute browser refresh.

**Architecture:** Store append-only quotes and an immutable article reference at the shared ingestion entrance. Public data goes through publication readers; visitors never trigger upstream fetching. A shared shell widget refreshes separately from cached HTML.

**Tech Stack:** Node TypeScript, PostgreSQL, pg-boss, Fastify, React Router.
