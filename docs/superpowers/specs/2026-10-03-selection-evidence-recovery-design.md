# 精选取证与纠错优化设计

用户已在 2026-10-03 的零精选诊断与实施建议后授权“按建议优化一波”。本次落实取证、纠错和运营可见性，保持 T1/T1_5/T2 门槛、预算及资金/攻击/监管/执行事实保护。校准数字需要代表样本，作为后续工作，不凭感觉降分。

## 选择与边界

降低分数只增加少量已核验候选；扩大信源数量仍缺关键原始材料。采用修复取证和有限纠错的方案，以今天已保存的高分案例及对抗样本验证。普通论坛和 X 不获得平台级一手许可。历史接受授权只有经审核确定为旧规则更严格时才能保留精确兼容；拒绝历史不得覆盖或清零。

## 取证

抽出独立 evidence-materials 模块，保持现有导出兼容。新增精确的财政部、OFAC、CFTC、Federal Register、reginfo 及 Arbitrum 文档主机，继续使用 SSRF 保护、HTTPS、逐跳域名校验、大小与时间限制。现有原文链接按与中文主张、原文标题的相关性选择最多两个，避免优先抓公司背景公告。不得开放式搜索或采用模型编造链接。

Arbitrum 官方论坛使用公开 topic JSON 验证：topic 第一帖、发布 username=Arbitrum、user_id=7、Security Council category_id=52，URL topic ID 与响应一致。只将该账号在该分类的正文认作其声明的一手材料；普通作者、回复帖、伪造域名、身份不符或元数据失败均不获得此属性。原论坛正文保留二手标记，另取经过身份验证的 primary 材料，现有公开指纹对原文的证明不变。

允许上述已核准主机的 PDF，使用固定版本的纯 JavaScript unpdf 库在有时间、内存、字节与页数上限的独立解析执行单元内提取文本，不运行脚本或访问 PDF 外链。PDF 不能解析或扫描件无文本则拒绝，不购买 OCR。所有 HTML/PDF/论坛材料记录来源 URL 和角色；限两个补证材料，不增加付费预算。

## 一手证据范围与精确引文

关键主张按条要求一手材料：攻击确认、损失金额、正式监管动作/结果、治理实际执行及其他核心安全事实。调用方依据中文文案和主张确定保护，正文背景里的 CEO/招聘监管/抽象治理词不会升级整篇。模型提供逐条 riskFlags，不能用空标记取消调用方的确定性关键事实保护。未提供逐条字段的旧响应继续采用原有整篇要求；明确要求一手的旧调用仍保持严格默认。

不取消任何 supported、主张覆盖、金额、数字、日期、链、阶段或逐字引文校验。给核验模型提供服务器切分并编号的原文段落；可引用 quoteId，由服务器解析回对应连续正文，未知 ID 拒绝。旧 exactQuote 仍按原规则检查，不进行模糊匹配或自动换标点。

## 有界纠错与发布

初次缺证可先补抓；无新材料、引文错误、摘要扩写或日期口径不足可进入唯一一次 rewrite。重写和最终核验都得到持久化的 original_copy 与原文标题作为不可变的核心对照，检查主体、动作和阶段；只删减无法支持的附属事实，若核心事实仍无证据，继续拒绝。最终核验显式检查核心事件没有被改成无意义占位内容。每轮最多三次 verification 付费尝试、一次 rewrite 付费尝试、两个补证材料；重写模型与配置身份固定，按 receipt_attempts 计数，错误/额度等待/未知结果/崩溃恢复不得另付费重试，可恢复已有成功回执。

规则版本纳入取证配置、主张策略、引用和恢复策略，确保改变语义会产生新指纹。旧严格规则的未重写 accepted 可精确兼容；旧重写在 original_copy_hash=final_copy_hash，或具体文章、旧规则、原始与最终文案指纹四者完全匹配已独立复查的核心保留记录时兼容。生产12条公开旧重写经逐条复查，11条核心事件保留（其中1条文案未变）；Sui 主网 TPS 改为链下通道的1条不进入证明名单。证明名单不能接受未知或修改后的文案，其余进入正常重新核验而不假定其满足新增的核心保护。存在新轮次时新轮次优先；历史 rejected 保留并通过正常分析入口进入新轮次。补扫只处理仍在 48 小时内的新鲜稿件，按已达精选条件和分数优先，有限批量，不重置或提高预算。验收记录旧重写授权受到的影响。

## 运营可见性

后台补充按当前文章版本的唯一文章计数：采集、PASS、评分达标、公开、精选，避免旧规则多轮记录误导接受率。显示取证失败的具体原因（不支持的入口、抓取失败、身份不符、PDF不可读、引用错误、真实缺证）；存在高分候选而长时间无精选时显示需要检查的状态。此后台读路径不发起模型调用或对外通知。

## 验证与发布

先增加生产问题和对抗情形的失败测试，再实现。覆盖财政部入口、相关链接排序、论坛账号/分类/帖子身份、PDF和限制、逐条证据、普通研究背景、关键攻击/金额/监管/执行、quoteId伪造、缺证重写和崩溃/额度上限、旧 accepted 兼容及新轮优先、唯一文章计数。完成独立空库全套后端测试、类型检查、前端构建/测试及本地 HTTP 冒烟。

部署前读核当前镜像/规则/预算，成功备份并固定回退镜像；只发布本次固定提交，不覆盖主目录既有信源修改，不跑覆盖生产配置的种子。验证真实候选接受/拒绝、网站/RSS/API/MCP的一致性、既有公开授权保留、暂停源没有恢复、预算仍受原设置约束。记录仍在额度等待或因过期/缺证无法恢复的文章，不更改原日期、不强行发布。
