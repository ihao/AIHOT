# 9BTC 行情与预测市场入口

站点通过 `site/modules/` 安装这个模块，框架的 API 和 worker 启动时分别注册 HTTP 接口、入库事件与定时任务；网页使用现有 root/sidebar 插口。

- `market.btc-usd` 每 5 分钟采集 Coinbase Exchange BTC-USD ticker。只有 `COLLECT_ENABLED=true` 才注册和执行，未设置、false 和其他值都关闭。
- `/api/v1/market/btc-usd` 从公开读取层返回最后一条已保存的行情；旧地址 `/api/site/market/btc` 继续可读。接口支持 ETag，没有行情时 `quote` 为 null。读者访问只读数据库。
- 新素材的首次成功插入在同一事务里绑定行情。入库时间使用数据库 `clock_timestamp()`，仅选择获取时间、成交时间均在此前 5 分钟内的行情。重见、正文修订和并发重复发现不再绑定；历史行、首次入库无可用报价的行永远保持未知。
- 行情采集只追加；失败或无效响应保留最后一条。初次 HTML 通过 root 模块数据插口读取 `/api/site/market/btc` 保存的行情；首屏只编码报价正常或延迟状态所需的稳定时钟，hydration 复用同一时钟，挂载后恢复真实时间。没有报价的时钟为 0，等价报价与状态不会因请求时间不同产生不同缓存内容；失败限时 2 秒并展示不可用。页面每 10 分钟读取同一站内接口，后台标签页暂停，恢复时立即读取；读取失败保留最后有效值，并展示延迟。报价与抓取时间任一超过 15 分钟也展示延迟。
- 预测市场是站点 taxonomy 配置的跨类别标签筛选。桌面标签栏、手机筛选菜单、搜索和精选无内容时的全部动态入口都传递同一个 tag 参数；普通标签仍保留框架原有独立筛选行为。

数据库表和列来自已经发布的 `0050_btc_usd_quotes.sql`，保留原始迁移和现有引用。针对本模块的测试使用本地响应和独立测试库，不连接 Coinbase 或模型服务。
