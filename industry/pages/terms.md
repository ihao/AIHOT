页首说明：

> 9BTC 整理 Web3 公开资料，帮助读者核对事实、追踪事件并回到原始来源。本站不是交易平台，内容不构成投资建议。

## 1. 内容与来源

本站优先整理可核对的事实与研究。文章标题、中文摘要、事件综述和报告可能借助模型生成，经编辑审核后才进入精选、热点或报告；符合限定条件的官方常规更新可以先进入“全部动态”。模型和人工编辑都可能出错，涉及金额、时间、协议状态或监管结论时，请以链接指向的原始资料为准。

原文版权归各来源方。本站默认展示自写摘要与原文链接；只有获得相应许可时才在站内展示来源全文。第三方网站的内容和服务由其各自负责。

## 2. 阅读与再利用

你可以免费浏览本站，并通过 RSS、公开 API 和 MCP 获取已公开内容，用于个人阅读、研究和组织内部参考。引用本站整理的摘要时，请注明“9BTC”并附上对应的站内页面及原文链接。批量复制、对外再分发或将本站内容作为商业产品的数据源，请先通过[反馈页](/feedback)联系网站运营方；原文的使用仍须遵守来源方的许可。

请勿通过高频请求、绕过限流或其他方式干扰本站运行。接口响应如提示缓存时间或返回 429，请遵守相应的轮询间隔与 Retry-After。

## 3. 更正与下架

如果你发现事实错误、失效链接，或作为来源方希望更正、下架、调整展示方式，请在[反馈页](/feedback)提供条目链接和具体理由。网站运营方会核对原始资料并处理请求；必要时会暂时撤下相关展示。

## 4. 服务边界

本站提供资料索引和信息整理，不提供交易、托管、投资顾问或收益承诺服务。内容可能延迟、不完整或有误；你应自行核验重要信息，并独立承担基于这些信息作出决定的风险。网站、RSS、公开 API 与 MCP 可能因维护或故障暂时不可用。
